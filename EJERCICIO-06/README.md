# Ejercicio 06 - Dashboard de métricas

## Qué he aprendido
- A crear un componente que se repite, el Metric, y pasarle datos diferentes cada vez
- A poner tarjetas en columnas usando flexDirection, flexWrap y gap
- A usar porcentajes para el ancho de las tarjetas

## Respuesta a la pregunta de comprensión
¿Por qué un ancho del 48% puede ser más práctico que 50% cuando además existe separación entre tarjetas?

Respuesta:
Porque con 50% no queda sitio para el gap y se descuadran, con 48% ya cabe.

## Qué he modificado
- He puesto el titulo y el subtitulo del dashboard
- He puesto cinco tarjetas de metricas: Ventas, Clientes, Pedidos, Conversión y Devoluciones
- Cada tarjeta tiene una etiqueta, un numero grande y el cambio en verde
- Las he puesto en dos columnas

## Resultado
Queda un dashboard con cinco tarjetas en dos columnas. La ultima, Devoluciones, se va sola a una tercera fila porque ya no caben mas en la fila de arriba. Cada tarjeta se ve clara, con el numero grande y el cambio en verde debajo.
